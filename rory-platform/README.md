# Rory Platform

Five Cloudflare sites:

- rorygpk.online: Control center
- show.rorygpk.online: Showcase
- chat.rorygpk.online: Chat
- complaint.rorygpk.online: Complaints
- mail.rorygpk.online: Mail administration

## Phase 1

This is a real foundation, not a fake finished system.

Included:
- Five hostname-aware site pages
- D1 schema for accounts, roles, sessions, content, files, chat, complaints, mail aliases, automation, and audit logs
- D1-backed maintenance mode
- Bilingual visual shell
- Fixed-background bicycle scroll scene
- Magnetic stair-card scene
- Private R2 and Mail Worker bindings
- AI coding-agent safety rules

Do not commit Cloudflare secrets, passwords, API tokens, verification codes, OAuth secrets, or owner credentials.
